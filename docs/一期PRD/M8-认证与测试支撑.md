# PRD · M8 认证与测试支撑

## 1. 目标
提供身份认证与访问控制基础，并建立覆盖全链路的自动化测试集，支撑回归与验收。

## 2. 范围
**含**
- 登录 / JWT 认证、未授权拒绝（401）
- 初始管理员播种（admin/admin123，可改）
- 冒烟测试（全链路 21 项）+ 专项验证脚本
- 真实文件导入端到端（上线退出条件）

**不含**：多角色/细粒度 RBAC（二期）；UAT 完整执行为上线前阶段任务。

## 3. 关键需求点
1. JWT 鉴权；未带 token 访问业务接口返回 401。
2. 测试集覆盖 登录→采集→复核→推送→溯源→看板 全链路。
3. 专项脚本：R006（平衡勾稽）、R003b（无户名→WARN 进复核）、API 联通（mock银企拉取）。

## 4. 验收 / 退出条件
- smoke_test.py TOTAL 21 / FAILED 0。
- 专项脚本全绿；一键回滚开关（金蝶 Mock↔真实）可用。

## 5. 依赖
- 全部模块完整性；真实网银导出样本文件（UAT 前提供）。

## 6. 状态
已落地（auth + deps + smoke/专项脚本）。UAT 与真实文件导入端到端待上线阶段执行（09-17 起）。

## 7. 涉及
`api/auth.py`、`api/deps.py`、`core/security.py`、根级测试脚本（smoke_test 等）。
