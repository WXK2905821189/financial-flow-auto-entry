# PRD · M6 看板与统计

## 1. 目标
为财务提供四块可视化看板 + 顶部统计卡，一屏掌握采集、复核、推送、异常全貌。

## 2. 范围
**含**
- 四看板：概览 / 银行分布 / 异常 / 对账
- 统计卡：待复核数、自动通过率等
- 数据检索与展示解耦（每看板对应 `v_*` 视图）

**不含**：多币种完整可视化、复杂下钻联动（后置于三期）。

## 3. 关键需求点
1. 四看板各对应一个 `v_*` 视图，检索与展示解耦。
2. 统计卡口径明确（回顾对齐：summary 口径已补丁）。
3. 跨库兼容：CASE WHEN 而非 MySQL 专属 IF()。

## 4. 验收 / 退出条件
- dashboard summary + 四看板端点均 200 且数据正确。
- auto_pass_rate 等口径符合规则（人工复核后下降正常）。

## 5. 依赖
- 上游各模块数据正确性。

## 6. 状态
已落地（api/dashboard.py + web/js/dashboards.js）。

## 7. 涉及
`api/dashboard.py`、`v_*` 视图、`web/js/dashboards.js`。
