# PRD · M7 设置与部署隔离

## 1. 目标
提供系统对接状态只读页；并明确生产环境的独立部署与网络隔离落地。

## 2. 范围
**含**
- 系统设置页：银行 / 金蝶 / 数据库 / 复核规则 对接状态只读展示
- 对接状态实时探测（如数据库 SELECT 1、金蝶 Mock↔真实）
- 凭据零泄露（不回传密钥明文）
- 生产部署：独立 MySQL 8.0 + Docker Compose + 独立内网/防火墙访问控制

**不含**：网页改写配置/凭据（凭据仅经环境变量/密钥服务注入，安全约定）。

## 3. 关键需求点
1. 系统设置页只读，状态徽章着色（绿=可用/真实、黄=Mock/待配置、红=异常）。
2. 接口不透出 sign_secret/app_secret/jwt 等任何密钥。
3. 生产 DB/Server 与办公网隔离；SQLite 仅演示。

## 4. 验收 / 退出条件
- 系统设置页可见且只读、不含密钥（接口实测零泄露）。
- 生产 DOCKER 化 + MySQL 建库（导入 financial_flow_schema.sql）可启动。

## 5. 依赖 / 卡点
