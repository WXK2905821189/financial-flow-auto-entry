# PRD · M5 溯源与审计

## 1. 目标
实现"银行流水 ↔ 复核记录 ↔ 金蝶凭证"双向可追溯，并对操作审计做防篡改留痕。

## 2. 范围
**含**
- 双向溯源：by-record / by-voucher 两个查询端点
- `aud_audit_log` 哈希链防篡改（append-only）
- voucher_no ↔ record_id ↔ raw_id 双向绑定
- 留痕时间字段（采集/校验/复核/推送各环节）

**不含**：区块链式外部存证（一期不需）。

## 3. 关键需求点
1. 任一凭证号可回查到原始流水；任一流水可查到推送凭证。
2. 审计日志追加写、哈希链校验，防篡改。
3. 环形外键避免：raw↔flow 用无循环双向引用。

## 4. 验收 / 退出条件
- smoke 覆盖 by_record / by_voucher 返回正确。
- 篡改验证可通过哈希链检出。

## 5. 依赖
- 贯通 M1 采集留痕、M3 推送凭证号、M4 复核结果。

## 6. 状态
已落地（api/trace.py + services/audit.py）。

## 7. 涉及
`api/trace.py`、`services/audit.py`、`models/aud.py`、`models/dwd.py`。
