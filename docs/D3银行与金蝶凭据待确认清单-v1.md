## 二、金蝶云星空 OpenAPI 凭据

现状：当前走 Mock 推送（`kingdee_mock_enabled=true`），金蝶侧无真实凭据。

### 2.1 官方资源

| 资源 | 地址 |
|---|---|
| OpenAPI 官网 / 文档 / 在线调试 | <https://openapi.open.kingdee.com/ApiHome> |
| SDK 下载中心（.Net / Java / **Python**） | <https://openapi.open.kingdee.com/ApiSdkCenter> |

技术形态：HTTP + JSON 的 RESTful 服务，18 个标准接口 + 1 个自定义接口，覆盖查看、保存、提交、审核、反审核、删除，含财务会计。官方提供 **Python 版 SDK**，与我们 FastAPI 后端同语言，可优先采用或其签名实现。

### 2.2 认证方式（主推）

「**第三方系统登录授权**」：系统管理 → 第三方系统登录授权 → 新增 → 点击「获取应用 ID」跳转 open.kingdee.com 完成授权 → 取得 `AppID` + `AppSec`。

（另支持 API 签名认证、集成密钥文件认证、旧版用户名密码认证，此处不展开。）

### 2.3 凭据清单（5 字段，待确认）
