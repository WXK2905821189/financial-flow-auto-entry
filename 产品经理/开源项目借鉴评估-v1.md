## 二、高价值：可重点借鉴

### 1. sebastienrousseau/bankstatementparser（Python · 43★ · Apache-2.0/MIT）

把「各种格式银行报表 → 统一流水模型」做到极致的开源库，几乎是一期「银行流水采集 + 数据中台 + 校验 + 复核」模块的参照实现。

项目地址：https://github.com/sebastienrousseau/bankstatementparser

| 它的能力 | 一期对应功能 | 借鉴点 |
|---|---|---|
| 统一 `Transaction` 模型 | D4 契约锁定 8+1 字段 | 归一化流水字段的标准定义方式 |
| 确定性解析优先 + LLM/视觉兜底 | D6 模拟API为主 + 文件导入兜底 | 多路径路由、确定性先行的分级方案 |
| Golden Rule 余额校验（期初+借−贷=期末） | R001–R005 校验 | 可替换/增强手写校验规则 |
| `transaction_hash` 幂等去重 | 中台批次幂等重导 | MD5 指纹，重复导入安全 |
| `source_method` / `confidence` 审计溯源 | audit 哈希链 | 每行可追溯来源的溯源方案 |
| 交互式 review（accept/edit/skip） | 复核工作台 | 人工复核交互范式 |
| 正则规则 `AccountMapper`（首条命中） | P1 对方科目规则预填 | 规则式科目匹配引擎实现 |

**局限**：支持的是 CAMT/OFX/MT940/ISO20022 等欧美格式，需自建中信/招商报表解析；PDF/OCR/多币种为可选能力，一期不必引入。

### 2. Bytsea/AiLedger（TypeScript · 2★ · 无许可证⚠️）

银行/信用卡流水自动分类 + 人工复核的 Web 应用。

项目地址：https://github.com/Bytsea/AiLedger

直接对标 P1 对方科目自动预填 + 复核工作台的可借鉴设计：

- **层次化分类引擎**：账套历史 → 客户历史 → 行业规则 → 全局规则 → AI 兜底（五级降级链）。
- **复核表**：显示预测来源、置信度、替代建议，允许人工覆盖。
- **规则 JSON 可配置**：可上传自定义会计规则、默认覆盖、重置。

**落地口径**：一期不做 AI，仅借鉴「规则 JSON 可配置 + 人工覆盖」流程；AI 智能匹配留待二期（P1 已定一期不做）。

**许可证提示**：未声明许可证，**仅可借鉴设计思路，不可复制代码**。
