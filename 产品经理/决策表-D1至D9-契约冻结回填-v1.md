## 三、校验规则 R001–R005（锁定）

| 规则 | 编码 | 级别 | 说明 |
|-|-|-|-|
| 重复流水 | R001 | ERROR | `dedup_key` 唯一索引冲突（同/跨批重复导入） |
| 负金额/方向非法 | R002 | ERROR | `amount ≤ 0` 或 `dc_flag ∉ {D,C}` |
| 必填字段缺失 | R003 | ERROR | 硬必填字段缺失 |
| 软必填缺失 | **R003b** | WARN | 对方户名/摘要缺失转人工（**从原 R003 拆分，见风险 R1**） |
| 单笔金额超阈值 | R004 | WARN | 单笔 > 50 万 CNY（默认，可配置） |
| 币种非法 | R005 | ERROR | 币种不在 ISO4217 合法取值 |
